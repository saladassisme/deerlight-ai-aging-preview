# Deerlight AI Aging Preview

Independent React + Vite + TypeScript + Tailwind website for Deerlight's AI-for-aging product ecosystem.

## Routes

- `/` — Homepage
- `/silver-os.html` — SilverOS
- `/skillhub.html` — SkillHub
- `/community.html` — Community
- `/labs.html` — Labs

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vercel detects the Vite configuration and deploys the `dist` directory.
